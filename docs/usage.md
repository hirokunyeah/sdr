# 使い方

## 基本の使い方（`desktop/sdr_app.py`）

### 起動
```
.venv\Scripts\python desktop\sdr_app.py
```

初回（または clone 直後）に `setup_windows.bat` でツールを展開しておく必要があります
（[install-windows.md](install-windows.md#2-ツールを展開するsetup_windowsbat)）。

### 画面の見方
- 上段のパネル：周波数・モード・ゲイン・音量・プリセットと「▶ 受信開始」ボタン。ボタンの上に状態（停止中／受信中／サーチ中／録音中）が表示されます
- 中央：スペクトラム（上）とウォーターフォール（下）。赤い線が今の受信周波数です
- 右側：局サーチで見つかった局の一覧
- 下端：周波数・音切れ回数などの詳細

### 基本操作
- 「▶ 受信開始」で受信。周波数・モード・ゲインは受信中に変更できます
- 音が聞こえないときは、2段目右の「音声出力」で出力先（スピーカー／ヘッドホン）を選びます
- 周波数は数値を入力して Enter、「−」「＋」ボタン（押し続けると連続）、またはマウスホイールで変更。1ステップは WFM で 0.1MHz、NFM/AM で 5kHz
- モードは WFM / NFM / AM のボタンで切り替え
- グラフをクリック、または赤い線をドラッグで選局。グラフ上のホイールで表示を拡大・縮小
- プリセットから FM放送・航空無線などにすぐ切り替え可能
- 雑音が多い・信号が飽和する場合はゲインを調整（25〜40dB 付近から試すのがおすすめ）

| 用途 | モード | 周波数の目安 |
|---|---|---|
| FM放送 | WFM | 76〜95 MHz |
| 航空無線 | AM | 118〜137 MHz |
| アマチュア無線 | NFM | 144〜146 / 430〜440 MHz |

### 局サーチ
1. 「サーチ範囲」で帯域を選び「📡 局サーチ」を押す
2. 見つかった局が一覧に表示されます。クリックで選局
3. 「◀ 前の局」「次の局 ▶」で順番に切り替え

サーチ範囲には、市民ラジオ(CB)・FM放送・航空無線・アマチュア144/430MHz・国際VHF(船舶)・盗聴器・特定小電力があります。
盗聴器のチェックは、部屋でラジオなどを鳴らしながら「盗聴器 398.4〜399.7MHz」をサーチし、その音が聞こえる局がないか確かめます（主な周波数はA 398.605／B 399.030／C 399.455MHz。プリセットからも選べます）。
「カスタム…」を選ぶと、開始・終了周波数、モード、ch間隔を指定できます（測定帯域幅と検出しきい値はモードに合わせて自動設定）。
所要時間は範囲の幅に比例し、0.8MHzごとに約0.5秒かかります。50MHzを超える範囲は、サーチ前に確認が出ます。

## 航空機の位置を地図に表示する（ADS-B）
「✈ ADS-B」ボタンで専用ウィンドウが開きます。旅客機などが 1090MHz で送信している ADS-B を受信し、
機体の位置・便名・高度・速度・方位を地図と一覧に表示します。

### 使い方
1. 「▶ 受信開始」を押す（メイン画面で受信中なら、自動で止めて ADS-B に切り替えます）
2. 受信できた機体が地図に飛行機のアイコンで表示されます。色は高度（低い：橙 → 高い：紫）、線は航跡です
3. 右の一覧の行をクリックすると、地図がその機体へ移動します（地図のアイコンをクリックすると一覧で選択）

- 地図の中心（赤い点）は気象衛星ウィンドウの「観測地点」の緯度・経度です。点線の円は 50/100/200/300km
- 位置は「偶数・奇数」2種類の位置メッセージがそろうと表示されます。便名・高度だけ分かっている機体は一覧に灰色で表示されます
- 60秒受信がない機体は消え、15秒以上位置が更新されない機体は地図上で薄く表示されます
- 地図の表示にはインターネット接続が必要です（地図データ：国土地理院「地理院タイル」）。右上のボタンで「淡色地図（暗）」「標準地図」「写真」を切り替えられます
- ADS-B 受信中は SDR を ADS-B 専用で使うため、メイン画面の受信は使えません。
  気象衛星の自動受信の時刻になると ADS-B は一時停止し、録音が終わると再開します
- ウィンドウを閉じると ADS-B の受信も止まります

### インターネットのデータも表示する
「インターネットのデータも表示」にチェックを入れると、ADS-B 共有サービス（adsb.lol または adsb.fi）から
受信地点の周辺（半径150海里・約280km）の機体を10秒ごとに取得し、自分で受信した機体と一緒に表示します。
- SDR で受信していなくても使えます（「▶ 受信開始」と同時に使うと、自局の受信と合わせて表示）
- 受信中に「■ 停止」を押すと、インターネットからの取得も止まります（チェックが外れます）
- 同じ機体（ICAO番号が同じ）は1機にまとめ、自分で受信した位置を優先します。便名・機種など自局で分からなかった項目はネットのデータで補います
- 位置がインターネットのデータの機体は、地図では薄いアイコンと「ネット」の表示、一覧では薄い文字、断面図では中抜きの点になります。
  自局で受信できている範囲（受信性能）を比べるのにも使えます
- 一覧の「位置」列は位置の出どころ（自局／ネット）、「機種」列は型式（ネットのデータから）です
- どちらも無料・非商用向けのサービスで、利用条件やアクセス回数の上限は変わることがあります。取得に失敗すると間隔を延ばして再試行します
- 地図の右下に出典（adsb.lol のデータは ODbL ライセンス）が表示されます

### 記録と再生
受信したデータをファイルに保存して、後から再生できます（SDR がなくても再生できます）。

**記録する**
- 「記録」にチェックを入れて受信すると、`desktop/adsb_data/adsb_日付_時刻.log.gz` に保存します
  （自局で受信したメッセージと、「インターネットのデータも表示」で取得した機体の両方）
- 受信（自局・ネットとも）を止めるか、チェックを外すとファイルを閉じます。保存先はステータス欄に表示されます
- ファイルの大きさは、自局の受信で1時間あたり数MB〜十数MBが目安です。異常終了しても、5秒前までのデータは読めます

**再生する**
1. 「記録を再生…」を押して記録ファイルを選ぶ（受信中なら止めて再生に切り替えます）
2. 地図・一覧・断面図が、記録したときの時間の流れどおりに動きます。受信地点は記録したときの地点になります
- 「⏸ 一時停止／▶ 再生」、速度（×1〜×60）、シークバーで好きな時刻へ移動できます
- 移動したときは、移動先の2分前から読み直して機体を作り直すため、航跡は直前2分ぶんから表示されます
- 再生中は「受信開始」「インターネットのデータも表示」「記録」は使えません。「■ 再生を終了」で元に戻ります

### 断面図（機体同士の位置関係）
地図の下の「断面図」は、受信中の機体を横から見た図です。横軸は基準からの水平距離（km）、縦軸は高度（ft）です。
- 基準は「選択した機体」と「受信地点」を切り替えられます。一覧・地図・断面図の点をクリックすると、その機体が基準になります
- 機体を基準にすると、その機体（◆）が左端に置かれ、他の機体には「水平距離 高度差」（例：`5.2km +725ft`）が表示されます
- 水色の帯は基準機の高度 ±1,000ft、点線は水平 5NM（約9.3km）。水平 5NM 未満かつ高度差 1,000ft 未満の機体は赤で表示します
  （管制のレーダー間隔の目安を参考にした表示で、受信データからの参考値です）
- 位置や高度が分からない機体は表示されません
- ホイール・ドラッグで拡大・移動、ダブルクリックで全機が入る表示に戻ります

### アンテナ
1090MHz の波長は約27.5cm です。付属のダイポールなら左右の棒をそれぞれ**約6.5cm**に縮め、
**縦向き**（垂直）に立てます。窓際や屋外など、空が広く見える高い場所ほど遠くの機体まで受信できます。

## 気象衛星の画像を受信する（Meteor-M LRPT）
「🛰 気象衛星」ボタンで専用ウィンドウが開きます。NOAA 衛星は2025年に運用を終えたため、
現在受信できる Meteor-M2-3 / M2-4（137.9MHz）を対象にしています。

### 準備
1. **SatDump を用意**（画像への変換に使う無料ソフト）
   - `setup_windows.bat` で展開済み（[install-windows.md の手順7](install-windows.md#7-気象衛星を受信する場合satdump)）
2. **アンテナを 137MHz 用の V字ダイポールにする**（付属のアンテナでOK）
   - 左右の棒をそれぞれ約53cmに伸ばし、120°に開いた V字にする
   - 地面と水平に置き、V字の開いた側を北か南に向ける
   - 空が広く見える屋外やベランダが理想。室内では受信が難しいことが多いです
3. **観測地点の緯度・経度を入力**（地図アプリで自宅付近を長押しすると確認できます）

### 使い方
- 起動すると軌道データを自動取得し、今後36時間のパス（衛星が上空を通る時間）を表示します
- 「自動受信」にチェックを入れると、最大仰角が設定値（初期値25°）以上のパスを自動で録音し、
  通過後に SatDump で画像に変換して右側に表示します
- 「● 今すぐ録音」で手動録音、「📂 録音ファイルをデコード…」で過去の録音を変換できます
- 「デコード後に録音ファイルを削除」にチェックすると、録音（1パス約0.8GB）を自動で消します
- 録音中は周波数などを変更できません。録音が終わると、録音前の周波数・モード（受信していなかった場合は停止状態）に自動で戻ります
- SatDump のデコード中はPCの負荷が高くなり、音が途切れることがあります
- ウィンドウを閉じても自動受信は続きます（アプリ本体は開いたままにし、PCのスリープも切っておく）

### 保存場所
| ファイル | 内容 |
|---|---|
| `desktop/satellite_data/<日時>_<衛星名>/` | 録音（`baseband_*.s16`）と変換結果（`decoded/`） |
| `desktop/satellite_settings.json` | 観測地点・SatDump の場所・自動受信などの設定 |
| `desktop/satellite_tle.txt` | 軌道データ（自動更新） |

「フォルダを開く」ボタンで保存先を開けます。

## 地域の統計を地図で見る（地域統計）
「🗾 地域統計」ボタンで専用ウィンドウが開きます（`python desktop/region_stats.py` で単独でも起動できます）。
人口・世帯・住宅・自動車・所得などの市区町村別の統計を、地図の色分けと順位の一覧で表示します。SDR は使いません。

### 使い方
1. 「指標」で見たい統計を選ぶ（初回は取得に数秒かかります）
2. 「年」またはスライダーで年（年度）を切り替えられます。選んだ市区町村の推移は右上のグラフに表示します
3. 「範囲」で都道府県を選ぶと、その中だけで色分け・順位付けし、地図をその都道府県に合わせます
4. 地図の市区町村や一覧の行をクリックすると選択できます。「市区町村名で探す」に名前を入れて Enter でも選べます
5. 「⌂ 観測地点」で、気象衛星ウィンドウの観測地点がある市区町村を選びます

### 推移を再生する
- 2段目のスライダーで年を切り替えられます。「▶ 推移を再生」を押すと、最初の年から順に地図・一覧が切り替わり、最後の年で止まります（途中で押すと一時停止）
- 「速さ」で1年分を表示する時間（0.5秒／1秒／2秒）を選べます
- 「全年で同じ色分け」（初期状態でオン）は、色の区切りを全部の年の値から決めます。同じ色が同じ値を表すので、年ごとの増減が色の変化で分かります。
  外すと年ごとに区切り直し、その年の中での差が見やすくなります
- 右側のグラフは、選んだ市区町村（水色）と表示範囲の中央値（灰色の破線）の推移です。赤い縦線が表示中の年です
- 年の間隔は指標によって違います（国勢調査は5年ごと、住宅・土地統計調査は5年ごと、軽自動車は毎年など）。データのある年だけを順に表示します

### 色分け
- 色は、市区町村がほぼ同じ数ずつ入るように7段階に分けています（暗い青：小さい → 明るい：大きい）。
  人口増減率・転入超過率は、0 付近を灰色、減少を赤、増加を青で表します
- 政令指定都市は区をまとめた市全体の値です（東京23区は区ごと）
- 持ち家比率・空き家比率・1住宅当たり延べ面積は、住宅・土地統計調査の対象の市区町村（約1,060）だけです。データがない市区町村は灰色になります
- 自動車は軽自動車等（軽四輪・二輪・原付）の台数です。普通乗用車の市区町村別の台数は、公開されている API がないため含めていません

### グラフで分析する
地域統計ウィンドウの「📈 グラフで分析」で開きます（`python desktop/region_charts.py` で単独でも起動できます）。
表示中の指標・範囲・選んだ市区町村を引き継ぎます。右側の「比べる市区町村」（最大6つ。名前を入れて Enter で追加）と「範囲」は、2つのタブで共通です。

**推移と将来の推計**
- 「比べる地域」に、全国・都道府県・市区町村を最大6つまで入れて、推移を折れ線で比べます。
  「＋ 全国」で日本全体、「＋ 都道府県」で「範囲」に選んだ都道府県全体を追加できます。名前を入れて Enter でも追加できます（「全国」「東京都」「流山」など）
- 単独で開いたときは「全国」だけが入っています。例えば総人口なら、日本の総人口の推移（1950年〜）と将来の推計がそのまま見られます
- 全国・都道府県の値は、統計ダッシュボードの全国・都道府県の値です（市区町村の値を足したものではありません）。総人口は1920年からあり、国勢調査の間の年は推計人口です。
  転入超過率のように全国・都道府県の値がない指標では、市区町村だけを表示します
- 点線は過去の傾向を延ばした推計です。推計の方法：「直線」は基にする期間の傾きのまま毎年同じだけ増減、「一定の伸び率」は年平均の伸び率のまま増減します
- 「基にする期間」は、推計に使う最近の期間（直近5年・10年・15年・全期間）です。「推計の終わり」は2030〜2050年
- 「試算：伸びの上乗せ」で、推計に毎年の上乗せ（マイナスなら下乗せ）をして「この先こうなったら」を試せます。単位は、割合（%）の指標ではポイント/年、それ以外は %/年です
- 総人口では「公式の将来推計も表示」で、国立社会保障・人口問題研究所の将来推計人口（2025〜2050年、5年ごと）を一点鎖線で重ねます。
  全国は「日本の将来推計人口」、都道府県・市区町村は「日本の地域別将来推計人口」です。下の表にも、推計の終わりの年の値を出します
- 「表示の開始」の「自動」は、全国・都道府県だけなら1950年から、市区町村を含むときは2010年からです。
  2010年より前の市区町村の値は平成の大合併の前の区域のもので、合併した市区町村はその前後で値が飛びます
- 「縦軸」の「指数」は、どの線にも値がある最初の年を100にそろえます（例：1975年＝100）。「対数」と合わせて、規模の違う地域の増え方・減り方を比べるのに使います
  （増減率などマイナスになる指標は実数のみ）。縦軸の単位はグラフの左上に表示します
- 「比べる基準」（初期値は表示しない）で、灰色の破線を足せます：
  - 「範囲の市区町村の中央値」：範囲の市区町村を値の順に並べた真ん中の値です（真ん中の市区町村の値で、全国の値ではありません）。
    年によって対象が入れ替わらないよう、表示する全部の年で値がある市区町村だけで計算します
  - 「範囲の合計」：全国なら日本全体、都道府県ならその都道府県全体の値です（人数・台数など足し合わせられる指標だけ）
- 下の表に、最新の実績と推計の終わりの値、その増減を表示します

**2つの指標の関係（散布図）**
- 横軸・縦軸に指標を選び、市区町村を点で表示します。点の大きさは人口、範囲内の点は青、範囲外は灰色です（範囲が「全国」のときはすべて青）
- 「▶ 年を進めて再生」で、年ごとに点が動きます。選んだ市区町村は色と名前で表示し、軌跡（それまでの年の位置）を線で結びます
- 軸は全部の年の値から決めて固定するので、再生中に点の動きがそのまま比べられます。値の幅が3桁以上ある指標（人口・人口密度など）は、初めは対数の軸にします
- 範囲内の市区町村で、相関係数と回帰直線（破線）を計算します。極端な値（上下0.5%）は除いて計算します
- 2つの指標の調査年が違うときは、それぞれその年以前で最も新しい値を使います（使った年を相関係数の右に表示）
- 点にマウスを重ねると値、クリックすると比べる市区町村に追加します。ホイール・ドラッグで拡大・移動できます
- 相関は「一緒に増減する傾向」を表すだけで、原因と結果の関係を示すものではありません

### 指標の一覧
| 分類 | 指標 |
|---|---|
| 人口 | 総人口、人口密度、65歳以上の割合、15歳未満の割合、人口増減率、転入超過率、昼夜間人口比率、外国人人口（10万人当たり） |
| 世帯・住宅 | 世帯数、1世帯当たり人員、65歳以上の単独世帯の割合、持ち家比率、空き家比率、1住宅当たり延べ面積 |
| 自動車 | 軽自動車等の台数、1世帯当たり軽自動車等の台数 |
| 所得・経済 | 納税者1人当たり課税対象所得、課税対象所得の総額、所得割の納税義務者数、完全失業率、事業所数（民営） |

### データの出どころ
| データ | 取得元 |
|---|---|
| 統計値 | e-Stat「統計ダッシュボード」API（総務省統計局。登録・キー不要） |
